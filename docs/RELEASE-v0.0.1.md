# v0.0.1 发行说明

这是夸克焦点延迟助手的首次开源版本，用于在特定 Android 14 设备上清除官方夸克 TV 的全屏蓝色焦点高亮，并保留实体遥控器暂停、继续与导航。

## 文件

| 文件 | 用途 |
| --- | --- |
| `QuarkFocusHelper-v0.0.1.apk` | 独立无障碍助手，显示版本名 0.0.1 |
| `quark-binder-agent.dex` | 由 ADB shell 启动的配套进程 |
| `SHA256SUMS.txt` | APK 与 DEX 的 SHA-256 |
| `scripts/device.py` | 安装、启动、调节延迟和停用工具 |

建议下载完整发布压缩包；单独 APK 必须配合相同版本 DEX 才能工作。

## 使用要点

- 仅 Android 14 / API 34；实测设备为 Samsung SM-F926U，播放器为官方夸克 TV 2.9.1702。
- 需要手动开启助手的无障碍权限，并执行 ADB 配套进程启动命令。
- 默认延迟 3 秒，从最后一次相关按键、窗口或焦点事件起算。
- 手机重启后需要重新通过 ADB 执行 `start`。
- APK 无桌面图标，从系统无障碍设置中管理。
- `versionCode=5`，便于覆盖此前内部测试版；签名证书保持一致。
