# 隐私说明

夸克焦点延迟助手不要求账号，不提供远程服务，不包含广告或分析 SDK。

## 运行时访问

无障碍服务拥有读取当前窗口结构和过滤按键事件的系统能力。当前实现只在官方夸克 TV 位于前台时处理导航、确认键及全屏焦点，读取窗口包名、焦点和控件几何边界，不读取控件文本或视频像素。APK 不申请互联网或存储权限。

Android 的无障碍权限本身能力较大，请以本仓库代码和自己安装的 APK 为准。用户可随时在系统设置中关闭此服务。

## 本地配置与日志

- 应用私有 SharedPreferences 保存认证密钥和延迟配置，禁用应用数据备份。
- 手机 `/data/local/tmp/quark-mode-config.txt` 保存配套进程密钥，文件权限设为 `600`。
- 启动工具用电脑临时目录传递密钥，成功或异常退出其上下文时自动删除临时目录，不在项目中保存密钥。
- Android logcat 与配套进程本地日志包含导航按键码、焦点状态、操作耗时、进程 UID 和执行结果；不会记录文本、账号、文件名或视频内容。
- 配套进程通过本机 Binder 通信，不打开网络端口；电脑与设备的无线 ADB 连接属于 Android 调试功能。

`uninstall` 命令卸载本助手并删除其配套 DEX、配置和日志文件。系统 logcat 由 Android 自行管理。仅停止配套进程时保留配置，以便再次运行。

## 构建时联网

`scripts/build.py` 首次构建时从 Google 和 GitHub 下载构建工具并核对 SHA-256。安装与运行控制脚本只调用本机 ADB，不向项目服务器上传内容。ADB 本身可能通过用户指定的局域网地址连接设备。

反馈问题时不要上传认证配置、配对码、登录二维码、网盘目录、完整未过滤日志或个人设备截图。这个仓库和发行包不包含原测试设备的网络地址、认证密钥或签名私钥。
